# lpinfo

Это команда **обнаружения**.

### Показать способы подключения

```
lpinfo -v
```

Например:

```
network ipp
network socket
network lpd
network smb
network ipps
```

или

```
network socket://192.168.0.125
```

означает, что найден принтер по JetDirect.

---

### Показать драйверы

```
lpinfo -m
```

Поиск драйвера:

```
lpinfo -m | grep Kyocera
```


# lpadmin

Главная команда администратора.

Создать очередь

```
lpadmin -p printer
```

Удалить

```
lpadmin -x printer
```

Изменить URI

```
lpadmin -p printer -v ipp://...
```

Установить драйвер

```
lpadmin -p printer -m everywhere
```

Включить

```
lpadmin -p printer -E
```

Сделать принтером по умолчанию

```
lpadmin -d printer
```

Tray
```
lpadmin -p <printer> -o media-source=tray-1 |by-pass-tray | auto
```

# lpstat

Диагностика.

Все сразу

```
lpstat -t
```

Принтеры

```
lpstat -p
```

По умолчанию

```
lpstat -d
```

Очередь

```
lpstat -o
```

Устройства

```
lpstat -v
```


# lp

Отправка файла

```
lp test.pdf
```

Выбрать принтер

```
lp -d kyocera test.pdf
```

Количество копий

```
lp -n 5 test.pdf
```

Двусторонняя

```
lp -o sides=two-sided-long-edge test.pdf
```

Лоток

```
lp -o InputSlot=Tray1
```

# cancel

Удалить задание

```
cancel 15
```

Удалить все

```
cancel -a
```

# poptions

Показать настройки

```
lpoptions -p kyocera
```

Установить

```
lpoptions -p kyocera -o sides=two-sided-long-edge
```


# ipptool

Это уже инструмент диагностики IPP.

Например, у тебя он уже показал, что принтер поддерживает:

- IPP 2.0;
- AirPrint 1.8;
- Duplex;
- PDF;
- PostScript;
- PCL XL;
- URI `ipp://192.168.0.125:631/ipp/print`.

Это одна из самых полезных утилит при работе с современными сетевыми принтерами.

Полезные тесты:

```
ipptool -tv ipp://ip/ipp/print get-printer-attributes.test
```

Проверка печати

```
ipptool -tv ipp://ip/ipp/print print-job.test
```
